# Motion AI Kit

Make your agent an animation expert.

Motion AI Kit gives your coding agent the skills and context to write production-grade animations with [Motion](https://motion.dev) and CSS. It works with Claude Code, Codex, Cursor, Amp, OpenCode, Gemini CLI, Copilot and any agent that reads a skills folder.

```bash
npx motion-ai
```

One command installs the Motion skills and connects your agent to Motion's hosted MCP servers. There is no API key. [Motion+](https://motion.dev/plus) features unlock when you sign in from your agent.

## What your agent gets

- **Animation best practices.** Hand-written advice from the creator of Motion, on taste and on technique, for vanilla JS, React, Vue, Base UI and Radix. It covers Motion and plain CSS, and when to choose each.
- **The latest Motion docs.** Your agent searches the full, current Motion documentation, so it never writes against an old API.
- **CSS spring generation.** Springs and bounces for CSS, generated by Motion as `linear()` easing.
- **Upgrades.** Ask for `/motion upgrade` and your agent follows the upgrade guide for the version you have installed.
- **Examples and Motion UI source (Motion+).** Search the source code of 450+ Motion Examples and Motion UI components, and add a Motion UI section to your project.
- **Transition editor (Motion+).** Tune a transition against a live preview, then apply it to your code through your agent.
- **Performance Doctor (Motion+).** Audit and fix animation performance. See below.

## Performance Doctor

Send any animation, component or page to Performance Doctor. It runs a static code audit or a runtime audit and grades every animation from S to F. Then it explains the cost of each technique and rewrites it at a better grade.

```
> /motion audit src/components
```

```

            A █████████░░░░░░░░░░░░░░  5 · 25%

src/Sheet.tsx:34 · Tier D
What:     `height` transition on `.sheet-panel`
Why:      height triggers layout, then paint, then composite, every frame
Upgrade:  Motion's `layout` prop (B) or a `scaleY` transform (S)
```

The audit method is served live from the Motion+ MCP server, so every audit uses the current MotionScore grading. For audits across a whole project, Claude Code and Cursor also get a `motion-reviewer` subagent that audits each area on its own.

## Performance Guard

Doctor fixes the animations you have now. Guard keeps them fast.

Guard audits your preview deployment on every pull request and posts the grade of each page as a comment. Set a threshold and it fails the build when any page grades below it.

```yaml
# .github/workflows/motionscore.yml
name: MotionScore Guard
on: deployment_status
permissions:
  pull-requests: write
jobs:
  guard:
    runs-on: ubuntu-latest
    steps:
      - uses: motiondivision/motionscore-guard@v1
        with:
          pages: |
            /
            /pricing
          threshold: A
          token: ${{ secrets.MOTIONSCORE_TOKEN }}
```

Pull request comments are free, with no account. The threshold gate needs a paid plan. Guard runs on your own CI runner, so it uses none of your audit allowance. It also works in any other CI through `npx motionscore`. Read the [Guard docs](https://score.motion.dev/docs/guard).

## Install

### Every agent

```bash
npx motion-ai
```

Choose a scope (this project or global) and one or more agents. The installer then:

- Copies the Motion skills into each agent's folder, for example `.claude/skills/`. For Codex, skills go to `.agents/skills/` and MCP configuration to `.codex/config.toml`.
- Adds the two hosted MCP servers:

| Server        | URL                           | Access                          |
| ------------- | ----------------------------- | ------------------------------- |
| `motion`      | `https://mcp.motion.dev`      | Free                            |
| `motion-plus` | `https://mcp.motion.dev/plus` | Motion+, sign in with OAuth     |

To use Motion+ features, open your agent's MCP menu and sign in to `motion-plus`. Your agent gives you a link. Nothing gets pasted into chat.

### Cursor

Open **Customize** from the sidebar, search the marketplace for **Motion** and install.

### Manual setup

If your agent is not in the list, add the servers yourself:

```json
{
  "mcpServers": {
    "motion": { "type": "http", "url": "https://mcp.motion.dev" },
    "motion-plus": { "type": "http", "url": "https://mcp.motion.dev/plus" }
  }
}
```

Agents that only support stdio servers can bridge with `npx -y mcp-remote <url>`.

## Usage

Write `/motion` in your agent, then ask:

- "Animate this modal in and out"
- "What options does `layout` have?"
- "Generate a CSS spring with a bounce of 0.3"
- "Add a Motion UI pricing section"
- "Audit src/Sheet.tsx for jank"
- "Upgrade from framer-motion"
- "Check the menu animation looks right"

Your agent also uses the skill without `/motion` when you work on animations.

## Animation inspector

Agents can't watch an animation, so the kit lets them step through one.
`filmstrip` pauses every Motion animation on a page, renders it frame by frame
and writes a contact sheet for your agent to read, plus a JSON timeline of
every animation that ran:

```bash
npx motion-ai filmstrip http://localhost:3000 --click "#open-menu"
```

It works with any page running Motion 14 or later, production builds
included, and adds nothing to your app: it listens on a hook Motion already
calls. It needs Playwright with Chromium. Agents that drive their own browser
can inject the inspector itself (`npx motion-ai inspector` prints it) and
pause, list and seek animations directly.
